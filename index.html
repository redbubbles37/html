Este é um parágrafo de introdução. A partir de agora, vamos aplicar diversas tags de formatação. Podemos usar a tag strong para dar forte importância semântica a um texto. Também podemos usar o texto sublinhado (underline) e o texto em itálico.

Para destacar visualmente um termo, como se estivéssemos usando um marca-texto, utilizamos a tag mark. Caso queira adicionar um texto de menor relevância ou notas de rodapé, a tag small é ideal para isso.

Tags de fórmula também são úteis: a fórmula da água é H2O (usando subscrito), e uma equação matemática comum é E=mc2 (usando sobrescrito).
